# dotfiles

Ma dot files (combined)

all dotfiles are completely custom from scratch (nothing copied from anyone else) unless explicitly mentioned otherwise (i cite my sources trust)

![terminal narrow](screenshots/terminal-narrow.png)

## components

**hyprland** (base): [TogiFerretFerret/hypr](https://github.com/TogiFerretFerret/hypr)

**quickshell** bar + widgets: [TogiFerretFerret/quickshell](https://github.com/TogiFerretFerret/quickshell)

btw the quickshell bar has the wallpaper picker included. (`touch /tmp/qs-wallpaper-picker` to open, there's a hyprland bind that does that [super-w])

**nvim** (super cracked): [TogiFerretFerret/nvim-dots](https://github.com/TogiFerretFerret/nvim-dots)

**fastfetch** (cooked fr): [TogiFerretFerret/fastfetch](https://github.com/TogiFerretFerret/fastfetch)

narrow mode fastfetch image courtesy of my good friend temp3st (realSpectro on github)

**fish** config: [TogiFerretFerret/fish-config](https://github.com/TogiFerretFerret/fish-config)

**swaync**: [TogiFerretFerret/swaync](https://github.com/TogiFerretFerret/swaync)

**rofi**: [TogiFerretFerret/rofi](https://github.com/TogiFerretFerret/rofi)

**matugen** templates: [TogiFerretFerret/matugen](https://github.com/TogiFerretFerret/matugen)

**ghostty** config: [TogiFerretFerret/ghostty](https://github.com/TogiFerretFerret/ghostty)

**mpv** config: [TogiFerretFerret/mpv](https://github.com/TogiFerretFerret/mpv)

**yazi** config: [TogiFerretFerret/yazi](https://github.com/TogiFerretFerret/yazi)

**sddm** (NERV theme): [TogiFerretFerret/nerv-sddm](https://github.com/TogiFerretFerret/nerv-sddm)

vaguely nerv inspired ig but i wuv da clock!!!!

**wallpapers** (very high quality trust): [TogiFerretFerret/wallpapers](https://github.com/TogiFerretFerret/wallpapers)
